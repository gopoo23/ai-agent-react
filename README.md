## 🚀 Getting Started

### 1. Clone the Repo
```bash
git clone https://github.com/gopoo23/ai-agent-react.git
cd ai-agent-react
```
### 2. Install Dependencies
This will install all the packages listed in package.json, including React, Vite, and the plugins used for this project.

```bash
npm install
```
### 3. Start the Development Server
Now, you can start the Vite development server:
```bash
npm run dev
```

## 🔌 API Setup
🔹 Google Gemini API
###To set up Google Gemini API for AI interaction, follow these steps:

Sign up and get your API key:

Visit Google AI Studio and sign up.

Obtain your API Key from the dashboard.

Add API Key to .env: In the root of your project, create a .env file (if not already present) and add your API key like this:
```bash
VITE_GEMINI_API_KEY=your_google_gemini_api_key
```
## 🔹 DumplingAI API
To use DumplingAI for text generation, summarization, and prompt handling:

Sign up and get your API token:

Visit DumplingAI and create an account.

Obtain your API token.

Add API Token to .env: Open your .env file and add the following:
```bash
VITE_DUMPLINGAI_API_KEY=your_dumplingai_api_key
```

## 🔄 n8n Integration
n8n is used for automating workflows and external API integrations. You can either run it locally or use a cloud instance.

Example Workflows: You can create workflows for scheduling AI queries, processing data from external APIs, or any task automation that suits your app.
